Import Members from CSV

How it works

Upload a CSV file exported from Excel or Google Sheets. The first row should have column headers like Full Name, Phone, Email, City, Work, etc. — we'll match them automatically. Columns we don't recognize are just ignored.

If someone's phone number (or email, if there's no phone) matches an existing member, we fill in any blank fields for them instead of creating a duplicate — we never overwrite information you've already entered. Rows with no name are skipped.
